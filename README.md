# Local SPA with a full UI on LittleFS in C++ (ESP8266)

Надійний, неблокуючий Single Page Application (SPA) вебсервер на базі мікроконтролера **ESP8266 (Wemos D1 mini)**. Проєкт використовує **PlatformIO**, файлову систему **LittleFS** для роздачі сучасного веб-інтерфейсу, а також забезпечує двосторонню взаємодію через **REST API (JSON)** та інтеграцію ультразвукового датчика відстані **HC-SR04**.

---

## 🚀 Основні особливості

* **Безпечна архітектура (State-Machine):** Обробка підключення до Wi-Fi через стейт-машину (`CONNECTING` -> `SUCCESS` -> `FAILED`), що повністю запобігає перезавантаженням через сторожовий таймер (WDT resets).
* **Захист від витоків пам'яті (OOM):** Маршрути вебсервера реєструються рівно один раз у момент успішного підключення до мережі.
* **LittleFS файлова система:** Швидка та ефективна роздача статичних файлів (`index.html`, `style.css`, `app.js`) безпосередньо з Flash-пам'яті ESP8266.
* **SPA Fallback:** Автоматичне перенаправлення невідомих запитів на головну сторінку для коректної роботи клієнтських роутерів.
* **REST API в реальному часі:** Ендпоінт `/api/data` у форматі JSON передає системний аптайм та актуальні дані з датчика відстані.
* **Неблокуюче опитування датчика:** Зчитування показників з HC-SR04 реалізовано через таймери `millis()` без блокування основного циклу виконання.

---

## 🛠 Апаратне підключення (HC-SR04)

| HC-SR04 Пін | Wemos D1 mini Пін | ESP8266 GPIO | Примітка |
| :--- | :--- | :--- | :--- |
| **VCC** | 5V (або 3.3V) | - | Рекомендовано 5V для стабільності |
| **GND** | GND | - | Загальна земля |
| **Trig** | D5 | GPIO 14 | Вихід тригера |
| **Echo** | D6 | GPIO 12 | Вхід відлуння (бажано через подільник напруги 5V -> 3.3V) |
